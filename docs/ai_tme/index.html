    AI Integration > TME Tissue Segmentation

    Abstract

    Tumor microenvironment (TME) segmentation streamlines histology image analysis by identifying various tissue types to help quantify and understand tumor heterogeneity.

    Models

    SegFormer MIT-B3 (Lung)

    SegFormer MIT-B3 (Lung) performs semantic segmentation. We used public annotations 1 to train Segformer 2 and DeepLabV3+ 3 models for TME segmentation. The training set included hematoxylin & eosin-stained (H&E) slides from breast and lung cancers in TCGA, combined with newly curated annotations from TCGA and four internal slides of surgically resected tumors, totaling 3403 patches (breast: 3110; lung: 293) at 0.44 μm/pixel. The models were trained to classify 10 tissue types: tumor, non-inflamed stroma, inflamed stroma, necrosis/hemorrhage, adipose tissue, bronchial epithelium, microvessel, foam-like macrophages, alveoli tissue, and muscle tissue. The performance of the model has been evaluated with pathological annotations (see reference).

    Model parameters:

    • Patch size (pixel): Default: 512x512. Options: 256x256, 512x512, 896x896.
    • Scale Factor: Default: 1/16. Options: 1/32, 1/16, 1/8.
    • Apply Color Normalization: Default: false.

    Model output:

    A labeled image with colors denoting different tissue types.

    Tissue colors
    • Non tissue, #000000 (Black)
    • Tumor, #8B0000 (Dark red/maroon)
    • Non-inflamed stroma, #FFFF00 (Yellow)
    • Inflamed stroma, #FF0000 (Red)
    • Necrosis/Hemorrhage, #FF00FF (Magenta)
    • Adipose tissue, #808000 (Olive/dark yellow)
    • Bronchial epithelium, #00FFFF (Cyan)
    • Microvessel, #0000FF (Blue)
    • Foam-like macrophages, #800080 (Purple/dark magenta)
    • Alveoli, #008000 (Green)
    • Muscle tissue, #000080 (Navy blue)

    Procedure

    The TME Tissue Segmentation side panel holds configurations for TME Tissue Segmentation.

    To initiate analysis, following the steps below:

    1. Select a model from the TME Model dropdown.
    2. Select appropriate options for model parameters.
    3. Click the Start TME Analysis button.
    4. The result should typically be available in a couple of minutes depends on the workload of the server and the size of the image. Once done, you will see statistics shown on the side panel below, such as tissue composition percentages.
    5. To show overlay of the result, click Show Results. The meaning of the overlay colors are displayed in the slide panel as well as mentioned above.
    6. Click Clear TME Results or Clear to delete analysis results.

    The analysis results will be persistent even after the web page is closed.

    To visualize the output,

    1. Click Remove to clean up previous analysis overlay from the current view. Note that this will only remove the display not the result. To re-enable overlay, click the Show Results again.
    2. You may toggle the overlay visbility using the Show/ Hide button.
    3. To adjust the display opacity, change the Opacity slider.

    The analysis results can be exported as a compressed folder (zip) by clicking the Export button. The zip file includes the labeled image of the entire image region and a json file containing image metadata and analysis results.

    Warning

    The new analyis result will overwrite the old one if the old result was not cleared.

    Info

    Due to downsampling, when zoom-ed in, the boundries of the tissue regions might appear to be blury, which is normal.
